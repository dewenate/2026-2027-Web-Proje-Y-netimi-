# 2026-2027-Web-Proje-Yonetimi-
2026-2027 Web Proje Yönetimi dersi için açılmıştır 
Akbaba Software - Detaylı Perakende Sistemi Kullanım Rehberi
📌 Projenin Amacı
Bu projenin temel amacı, Akbaba Software tarafından geliştirilmiş olan Detaylı Perakende ve Depo Yönetim Sistemi'nin kullanımına dair kullanıcılara rehberlik eden, anlaşılır ve erişilebilir bir web sitesi sunmaktır.

Yazılımı kullanacak personellerin ve yöneticilerin sistemi en verimli şekilde öğrenebilmelerini sağlamak adına hazırlanan bu rehber web sitesi; stok yönetimi, barkodlu satış, depo hareketleri ve raporlama gibi modüllerin nasıl çalıştırılacağına dair adım adım açıklamalar sunar.

🚀 Proje Özellikleri
Adım Adım Kullanım Kılavuzu: Perakende ve depo sistemindeki işlemlerin (ürün ekleme, stok güncelleme, satış yapma vb.) detaylı açıklamaları.

Kullanıcı Dostu Modüler Yapı: Aranan bilgiye hızlıca ulaşmayı sağlayan sade ve açık sayfa düzeni.

HTML Tabanlı Mimari: Standart web teknolojileri kullanılarak oluşturulmuş hafif ve hızlı web yapısı.

🛠️ Kullanılan Teknolojiler
HTML5: Web sitesinin metinsel içeriği, başlık hiyerarşisi ve sayfa yapısı.

(Geliştirme aşamasına göre CSS3 ve JavaScript eklenebilir)
